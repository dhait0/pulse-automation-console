# Decisions

## Static synthetic data

The project uses static synthetic data to remain publishable and safe while still communicating real enterprise workflow experience.

## Bilingual copy

English and Spanish are paired in concise labels instead of creating two separate apps. This keeps the interface quick to scan for clients.

## Distinct visual system

The design avoids repeating the previous dashboard and access portal structures. It uses denser information layout, square edges, a light canvas, and operational status tones.

## No backend yet

This third demo introduces automation concepts without adding a full API layer. A later project can add Node.js, NestJS, Prisma, PostgreSQL, queues, and webhook verification.
