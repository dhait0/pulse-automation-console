# Implementation

The app is implemented with Next.js App Router and strict TypeScript.

## UI approach

The interface uses an operations-console layout:

- persistent left rail on desktop
- dense workflow table
- webhook event grid
- incident and runbook panels
- connector surface

The visual direction intentionally differs from the previous portfolio demos by using a light operational canvas, strong black rules, compact rows, and status colors.

## Screenshots

Screenshots are generated by `scripts/capture-screenshots.mjs` with Sharp. They are stored in `public/screenshots/` and referenced from the README.
