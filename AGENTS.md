# Mission

Build a bilingual automation operations demo that feels like a real workflow monitoring product.

## Product rules

- Keep this repo visually distinct from the dashboard and access-control demos.
- Use a console-like information architecture with dense, scannable operational data.
- Avoid generic cards, repeated section rhythm, and marketing-page composition.
- Pair English and Spanish labels so clients can understand the product quickly.
- Use only mock workflows, fake webhooks, fake users, and synthetic execution metrics.
- Treat AI as support; final UI decisions must look intentionally directed.

## Repository standards

- Include `README.md`, `docs/`, `LICENSE`, `.env.example`, `.gitignore`, and screenshots.
- Keep code production-ready with TypeScript strict mode.
- Document architecture, implementation, decisions, and future improvements.
